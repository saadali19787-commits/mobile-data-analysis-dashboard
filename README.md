🔷 PROJECT OVERVIEW


This project analyzes mobile phone data to understand:


Price trends


Brand comparison


Processor performance


RAM, battery & refresh rate impact on price




Goal:
👉 Identify what features affect mobile price the most
👉 Compare brands and specifications visually using dashboard


👉 Simple line (GitHub use):

This project analyzes mobile phone specifications and their impact on pricing using an interactive Excel dashboard.

RAM

👉 Simple: “Mobile specs + price data”

Removed duplicate records


Handled missing values (blank → cleaned/ignored)


Standardized brand & processor names


Converted:


Price → numeric


RAM / Storage → numeric




Created new categories:


Price Category → Budget / Mid-Range / Premium / Flagship


Grouped RAM values




Ensured all columns are consistent for analysis
